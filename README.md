## **Project Overview**
SmartCampus Automation optimizes academic workflows such as **attendance tracking**, **homework submissions**, and **weekly report generation**.  
This project demonstrates the application of:
- **Automation concepts (RPA)** – automating repetitive tasks like attendance updates and notifications  
- **Data Analytics** – analyzing module data to generate actionable insights  
- **Generative AI (conceptual)** – generating weekly report summaries  

It is designed to showcase **workflow optimization, process improvement, and digital transformation concepts** in a concise, demo-friendly format.

---

## **Key Features**
- **Attendance Automation & Notifications (RPA Concept)** – Marks attendance and simulates reminders for absent students  
- **Homework Submission Analytics** – Calculates submission rates and visualizes trends  
- **Weekly Summary Reports (Generative AI Concept)** – Generates concise module performance summaries  
- **Workflow Playbooks & Documentation** – Ensures replicable processes and knowledge transfer
